# Chi Squared Test of Independence for Internal Audit

This code demonstrates an implementation of Chi Squared Test of Independence. Its purpose is to show how this statistical technique can be used in an Internal Audit context. 

The example is a ficticious but realistic scenario from a healthcare setting,. The sun is to answer the question of whether patients with additional care needs are more likely to be readmitted within 30 days. However, this method could be applied to any insurance where there is a target risk factor (for example, readmission flag) and subpopulations within the data (for example, the kind of post discharge care which patients require). 

Data for this example were generated by Google Gemini. They are therefore fictitious and do not represent data from a real healthcare provider. 

Packaged code in chi_2.py can be repurposed for your own context.
