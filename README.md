# Third Line

I write about applied data science for internal auditors in my newsletter on Substack, [Third Line](https://thirdline.substack.com/). 

This repo contains code and scripts to implement approaches referred to in the newsletter. 

Code can be repurposed for your own internal audit use cases. However, please ensure that it's fit for purpose prior to use in assurance work. 

### Data

While I draw on my experience, all data and ‘results’ are ficticious and illustrative only, and do not represent outcomes of audits that I've worked on for my employers, past or present
